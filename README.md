# neurovim.nvim

NeuroVim — a Vim-learning spy thriller — as a Neovim plugin.

![License: AGPL-3.0](https://img.shields.io/badge/license-AGPL--3.0-blue)

**Status:** in development (phase 3 of 5 done). The game logic — scoring, progression, par tiers — is ported to Lua and passes all 83 conformance vectors from NeuroVim's TypeScript core. The interface (NEXUS, briefings, missions) follows in phase 4; not installable yet.
